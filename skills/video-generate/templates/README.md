# Script templates — Phase 2, not written yet

PROJECT.md §9.4 calls for three:

- `app-showcase` — phone/app UI in motion (fintech, games, apps)
- `product-hero` — product close-ups (DTC, food, consumer goods)
- `lifestyle` — a person using the service in context

Each template describes scene, motion, camera, light and mood, and must explicitly forbid
text, letters, logos and watermarks in the generated footage (PROJECT.md §3 rule 3).
Real logos are composited afterwards by `scripts/brand_overlay.py`.
