# Reference library

- `raw/` — the "good examples": high-quality mission videos from Igor/Sidney's Drive folder.
- `negative/` — what we do **not** want: corporate, low-effort influencer UGC, blurry, wrong format.

Both are git-ignored. **Never commit media.**

This is not model fine-tuning. The library is used to (a) derive a written style profile and
calibrate the rubric, and (b) provide visual references and keyframes for generation prompts.
